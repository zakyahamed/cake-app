# Step 11 — Bookings

## Objective

Implement service booking.

## Customer

Customer can:

- Select service
- Select date
- Select time
- Submit booking
- View booking
- Cancel where permitted

## Business

Business can:

- View bookings
- Confirm
- Reject
- Complete
- Cancel

## Status

PENDING
CONFIRMED
COMPLETED
CANCELLED
REJECTED

## Important

Prevent obvious double-booking conflicts.

For MVP, use simple availability rules.

Do not build a sophisticated scheduling engine.

## Definition of Done

Customer booking flow works end-to-end.
