# Step 08 — Search and Discovery

## Objective

Implement marketplace discovery.

## Search

Search:

- Businesses
- Products
- Services

## Filters

Support:

- Category
- Location
- Rating
- Price
- Fulfilment options

## MVP approach

Use PostgreSQL search initially.

Do NOT introduce Elasticsearch or another search engine for MVP.

The architecture should allow a dedicated search engine later.

## Requirements

Implement:

- Pagination
- Sorting
- Search
- Filtering
- Distance/location filtering where practical

## Definition of Done

Frontend search can replace mock search with API search.
