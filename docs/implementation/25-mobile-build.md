# Step 25 — Mobile Application

## Objective

Connect the already-built customer mobile frontend to the production API.

Do not rebuild mobile features.

Replace mobile mock repositories with API repositories using the same backend contracts.

## Verify

- Authentication
- Discovery
- Search
- Business profiles
- Products
- Services
- Cart
- Checkout
- Payments
- Orders
- Bookings
- Messaging
- Reviews
- Notifications

## Build

Create:

- Development build
- Staging build
- Production build

Verify Android and iOS separately.

## Definition of Done

Mobile app operates against staging backend.
