# Step 20 — Security Review

## Objective

Perform security hardening before production.

Review:

- Authentication
- Authorization
- Input validation
- Rate limiting
- CORS
- Security headers
- SQL injection protection
- File upload security
- Payment verification
- IDOR protection
- Sensitive data exposure
- Logging
- Secrets

## Important

Never trust:

- User IDs from client
- Business IDs from client
- Prices
- Payment status
- Order status
- Roles
- Ownership

All must be verified server-side.

## Definition of Done

Security checklist passes.
