# Step 26 — App Store and Play Store Submission

## Objective

Prepare customer mobile application for public distribution.

## Requirements

Prepare:

- App name
- App icon
- Splash screen
- Screenshots
- Store description
- Privacy policy
- Terms
- Support contact
- App privacy disclosures
- Data collection disclosures

## Android

Create production signing configuration.

Create release build.

Test on physical Android devices.

## iOS

Create production signing configuration.

Create release archive.

Test through Apple's beta distribution workflow.

## Important

Do not submit until:

- Authentication works
- Payments work
- API is production-ready
- Privacy documentation exists
- Account deletion requirements are addressed where applicable
- Critical crashes are resolved

## Definition of Done

Both store submissions are ready.
