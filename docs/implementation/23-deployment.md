# Step 23 — Deployment

## Objective

Deploy the MVP backend and web frontend.

## Environments

Create:

development
staging
production

Do not develop directly against production.

## Deployment

Deploy:

- PostgreSQL
- NestJS API
- Web frontend
- Object storage
- Required background jobs if any

## Requirements

Configure:

- HTTPS
- Environment variables
- Database migrations
- CORS
- Domain
- Health checks

## CI/CD

Pipeline should run:

1. Install
2. Lint
3. Typecheck
4. Tests
5. Build
6. Deploy

## Definition of Done

Staging environment is fully functional.
