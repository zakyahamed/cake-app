# Step 13 — Messaging

## Objective

Implement customer-business messaging.

## MVP

Use REST polling/refetching.

Do NOT introduce WebSockets unless required.

## Features

Customer:

- Conversation list
- Send message
- View messages

Business:

- Conversation list
- Reply
- View customer
- View related order

## Rules

Only participants can access a conversation.

Messages must be authorization-protected.

## Definition of Done

Customer and business can communicate through API.
