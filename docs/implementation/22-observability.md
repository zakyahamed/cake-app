# Step 22 — Observability

## Objective

Make production problems diagnosable.

Implement:

- Structured application logs
- Error logging
- Request IDs
- Health checks
- Database health checks

Do not log:

- Passwords
- Tokens
- Card details
- Sensitive personal information

Create a basic error monitoring integration if selected for the project.

## Definition of Done

A production error can be traced without exposing sensitive data.
